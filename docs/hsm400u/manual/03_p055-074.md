# Mikron HSM 400U manual, pages 55-74: block scan, smart machine modules (APS, ITC), M-functions, machine/user parameters

Source: `Mikron_ohjeet_s55_74.pdf` (20 scanned pages, manual pages 55-74; page footer "HSM 400 / HSM 400U iTNC").

Original language: English (Mikron English edition).

Overview: these pages cover restarting a program from a block (block scan), then the "smart machine" options. APS measures spindle vibration and records it for the spindle warranty (cycle 303). ITC compensates thermal drift of X/Y/Z, and cycle 307 recalibrates the C-axis pivot point. After that comes the complete Mikron M-function list, standby mode, the two spare user outputs (O29/O30), and how to open the general and machine-specific user parameters. The section on user parameters continues in the next file.

Note: the manual names the control **iTNC 530** throughout these pages, not iTNC 520.

## 4.5.10 Starting a block scan (p. 55)

1. Close the protective doors.
2. Switch the drives on with the POWER ON/OFF key (S/H171).
3. Press soft key "RESTORE POS. AT N".
4. Enter BLOCK SCAN TO N = NC block number [ENT], PROGRAM = program number [ENT], REPETITIONS = repetition count (needed when the re-entry point is inside a program-part repetition).
5. Press NC-START (S520). The control (COU) calculates up to the selected block.
6. Press soft key "RESTORE POSITION". A "Restore machine status" screen appears (example shows `S5000 M11 M87`).
7. Press NC START (S520) to restore the machine status. Then re-approach the contour (see 4.5.8 "Reapproaching the contour with position logic").

- Caution: collision danger. The axes move from their current position when re-approaching. They can first be moved out of the collision range (see 4.5.5 "Traversing the machine axes during an NC stop").

Fig.: the screen "Program run, full sequence" shows a load bar (0-150 % LOAD), positions, S, F, M 5/9 and an "INTERNAL STOP" soft key.

## 4.6 Modules smart machine

### 4.6.1 APS (Advanced Process System) (p. 56)

- The motor spindle has a **vibration sensor** that measures vibration during cutting and sends it to the control. The measured value G is a multiple of the speed [as written].
- While the spindle turns, **F1** shows a gauge bar of spindle vibration. Pressing F1 again changes the resolution: 10G, 5G, 2.5G, 1G.
- Display example: `SPINDLE VIBRATIONS  A: 3.10  S: 4.00  Z:10.00`.
- Normal operation is below 1G. Values above 2G are possible without damage. **Above 3G** is not normal operation and risks damage to the spindle and machine. The gauge bar turns red.
- Exceeding the limits does not void the spindle warranty immediately. All values are logged, and F1 shows them.
- Time spent in each vibration class is logged. Example: `0-3G=799:52:29  3-5G=47:12:08  5-7G=1:17:56  7-10G=2:32:23`. An "!" warns of too much time in a class.
- Spindle life drops progressively with the G class. The remaining guaranteed life is shown with F1. Example: `SPINDLE WARRANTY Ini=4000 Eff=28:47:50 Rem=2971:36:41`.

### 4.6.2 APS extended (Cycle 303) (pp. 57-60)

- Cycle 303 extends tool life by measuring vibration when the spindle speed rises and logging it to a table. It is a paid option.
- Figures compare an inappropriate load (spikes up to about 10G) with an appropriate one (about 2-4G, under the "OPTIMAL" line) over a time axis of 205-240 s.

Cutting data for the optimal example:

| | Before | Optimized |
|---|---|---|
| Advance | F3000 | F4000 |
| Speed | 10000 | 6000 |
| Feed | 0.5 mm | 0.3 mm |
| Dip angle | As required | [blank] |

- Note: spindle vibration load depends directly on the CAD/CAM programming and the NC programs.
- Warning: avoid spindle loads above 3G. All loads are logged in the background, and overloads shorten the spindle warranty.
- The remaining warranty is shown by pressing F1 five times.

**Recording on/off:**
- In CYCL DEF 303, an input mask sets the sampling interval of the G sensor. Values below the limit are not logged.
- Recording stops if the sampling frequency or the limit is 0, or at M2/M30. Re-arm it with a new 303 cycle.
- M5 or NC Stop pauses recording. It resumes at the next M3/M4 or NC Start.

**Gauge bar:**
- Shown with F1 when the safety circuit is closed and the spindle is turning.
- Light blue below the limit, red above it. Without cycle 303 the bar turns red above 3g.
- The display reads A = actual value, S = NC Stop value, Z = zoom. Zoom choices are 1.25 / 2.50 / 5.00 / 10.00.
- An NC Stop is executed when the S value is exceeded.
- The display switches off when the door opens. F1 turns it on again, and CE returns to the spindle-load display.

**Cycle 303 parameters (p. 59):**

| Q | Meaning | Range |
|---|---|---|
| Q394 | Sampling frequency [s] | 1-60.0 s |
| Q395 | G sensor limit [g] | 0.0-10.0 g |
| Q388 | Program stop limit [g] | 0.0-10.0 g |
| Q389 | Program message limit [g] | 0.0-10.0 g |

- Data goes to `TNC:\Apslog.tab`, which holds at most 18,000 rows. Before PLC software H2I07 the file was called `Vibrset.tab`.
- Example: Q394 = 5 s writes a row every 5 s. When the limit is exceeded continuously, the file wraps to row 1 after 25 h and is fully overwritten after another 25 h.
- Vibroset.tab columns: NR, DATUM, AKTWERT, MAXWERT, STOPWERT, DREHZAHL, WKZNR, VORSCHUB, NCSATZ, PGMName. Example rows from 13.11.2002 show 2.50/2.00/0.00, speed 1007, tool 1, feed 1030.
- Apslog.tab columns: NR, DATE, ACTVAL, LOGLEV, STOPLEV, MESSLEV, SPISPEED, TOOLNR, VELOCITY, NCSENT, PGMNAME. Example rows from 18.01.2004 show a spindle speed of about 10149-10150 and tool 7.
- If Q388 is exceeded, the program stops. If Q389 is exceeded, message "42 Spindle vibration too high" appears.
- **M86** resets TNC:\APSLOG.TAB so recording restarts at row 1.
- Note: if TNC:\APSLOG.SAV is copied to APSLOG.TAB, run M86 before the next cycle 303.

Example program:
```
1 L M86                         ; index Vibroset.tab to zero
2 CYCL DEF 303 spindle vibrations
    Q394=+1  ; sampling [s]
    Q395=+2  ; max G value [0...10]
    Q388=+0  ; max G value for PgmStop
    Q388=+0  ; G message   (printed as Q388; presumably Q389)
```
- Spindle hours per G category are displayed as above. An "!" means the value was reduced in proportion to the base value 0-3G. It is too high and will damage the spindle permanently.

### 4.6.3 ITC - Intelligent Thermal Control (pp. 61-62)

- ITC compensates thermal shifts of the machine structure at the cutting point in X, Y and Z, caused by internal heat sources.
- Following DIN 8602, process heat and external heat sources are **not** measured.
- Modular: one ITC axis module per axis (X, Y, Z). Standard on some machine types, an option on others, and can be retrofitted.
- Thermal precision of about ±8 µm (printed "±8 ?m") per linear axis is possible when Mikron's operating conditions are followed.
- ITC is delivered on and optimized. It can be switched on/off per axis via the user parameter list. Mikron recommends leaving it on.

Tips for higher precision:
- For demanding finishing, use the warm-up cycles: spindle warm-up M302, tool warm-up M300 (cross-reference "Chapter 4.6.1" as printed). Wait about 2 min after a tool or speed change.
- After long or heavy use, or after message "76 ITC WAS INITIALIZED AGAIN", run the spindle for 15 min at S max before machining. Then let the machine run 1 h with the axis drives on and the main door locked.

### 4.6.4 ITC 5axis (Cycle 307) (pp. 63-66)

Purpose: heat shifts the swivel point of a 5-axis machine, which causes errors with cycle 19, M128 and PLANE functions. On the HSM 400U, cycle 307 finds the **C-axis centre of rotation**. It measures the change of that centre in a hole of a workpiece, or of a measuring pallet, with a 3-D touch probe.

Requirements:
- iTNC 530 from NC software 340 422 10.
- 3-D touch probe, with tool name exactly `TOUCH PROBE` in the tool table.
- Tool measurement (laser or TS 27) recommended.
- HSM 400U: measuring pallet or plug gauge with a hole/plug at the C-axis turning centre (from the pallet maker or self-made).
- Accuracy depends on probe calibration.

Use it before high-precision 5-axis work (cycle 19, M128, PLANE) and when the ambient temperature changes significantly.

Input mask `CYCL DEF 307 ITC5AX` (German comments in the original):

| Q | Original comment | Meaning | Default |
|---|---|---|---|
| Q378 | Umschlag Messen | Change measuring. 0 = none: HSM and Vario measure in the C-axis turning centre, UCP 800 Duro measures on the turning-plate surfaces. 1 = active: measure a hole in the workpiece or pallet. 3 = Vario: eccentric hole in a large pallet | 0 |
| Q379 | Messposition X | X of the hole from the table centre at C = 0° (M91). 0 on UCP 800 Duro = measure plate surfaces | 0 |
| Q380 | Messposition Y | Y of the hole from the table centre at C = 0° (M91). Same Duro note | 0 (example value +45) |
| Q381 | Messhöhe Z | Z measuring height from the pallet or plate surface, if different (exact to ±0.003) | 0 |
| Q382 | Messart Innen/Aussen | 0 = Ø10 bore. Negative = bore Ø (e.g. -15). Positive = plug gauge outside Ø (e.g. +40) when there is no REF pallet | 0 |
| Q383 | Palettennummer | -1 = REF pallet inserted manually. ≠ 0 = number of the REF pallet in the WPC, loaded automatically | -1 |

Measurement options by machine type:

| Profile | Turning centre (REF pallet) | Eccentric simple | Eccentric for change |
|---|---|---|---|
| Hole | HSM, UCP 600 Vario | UCP 600 Vario (large table) | HSM, UCP 600 Vario, UCP 800 Duro |
| Surfaces | – | UCP 800 Duro | UCP 800 Duro |

Function cycle on the HSM 400U ("e" 0" in the scan read as ≠ 0):
1. Read out the current tool number and speed.
2. Store the active pallet number (only if Q382 ≠ 0, as printed; probably Q383 [uncertain]).
3. Deactivate cycle 19 for program run and manual mode.
4. Read out the current reference point.
5. Load measuring pallet Q383 (only if Q383 ≠ 0).
6. Measure the hole in the pallet or workpiece in X and Y.
7. Measure the top surface next to the hole in Z.
8. Change measuring: turn the C axis by 180°.
9. Change measuring: measure the hole in X and Y again.
10. Compare the REF coordinates with the current values. If the difference is > 0.07, show "Tolerance exceeded".
11. Write the new REF coordinates to the control and to `TNC:\Cycle_307\List-RP.A`.
12. Restore the previous tool and reference point.
13. Re-insert the pallet that was loaded before (only if Q383 ≠ 0).

Fig.: REF pallet HSM 400U (3R): round pallet with a probe stylus in the centre bore.

Log file `TNC:\Cycle_307\List-RP.A` ("ROTATIONPOINT OF C-AXIS"):
- Holds the kinematics-table data (C-axis turning point coordinates). Open it only in storage/edit mode.
- Warning: the file must not be open while the cycle runs. The newest values are at the end.
- Each entry has a date/time, dX/dY/dZ (change since the previous run) and X/Y/Z (current point).
- Example from 10-07-2003: dX 0.0001-0.0002, dY 0.0000, dZ 0.0002-0.0018. X ≈ -51x.404 [first digits uncertain], Y = 243.8850 [uncertain], Z ≈ -50.58 (-50.5827 / -50.5834 / -50.5836).

Sources of error: probe errors, chips on the measuring surfaces, a wrong Z height Q381.

IMPORTANT:
- The M92 coordinates are updated after each calibration but may live only in RAM, not in the MP. After a REBOOT they are no longer active, and the values from **MP 950** apply until the next cycle 307 or an Emergency Off.
- All presets are calculated from the C-axis turning point and update after calibration (use PRESET where possible).
- "Spindle On" and "Coolant On" do not restart automatically after the cycle.

### 4.7.2 Standby mode (p. 71)

- M77 switches off the hydraulics (HYP), fans, work lamp, screen, etc. The control (COU) stays active to keep communication with higher-level systems.
- Restart with POWER ON/OFF (S/H171), the same as after an emergency stop.

### 4.7.3 Spare outputs at disposal (p. 71)

| Output | Connection | Max load | Set | Reset |
|---|---|---|---|---|
| O29 | A500/X510-24 | 2 A | M79 | M78 |
| O30 | A500/X510-31 | 2 A | M81 | M80 |

- Note: the outputs can carry 2 A with relay output board 958.74.509.
- Warning: the outputs are **not** reset on EMERGENCY STOP.
- To wait for feedback, FN18 reads any control input into a Q parameter: `FN18: SYSREAD Qxx = ID2000 NR20 IDXyyy` (xx = Q 0-99, yyy = input number). The result is Qxx = 0 for inactive and 1 for active.

Example `TEILEN.H`: a rotary indexer gives feedback after indexing. It uses output O29 (M79/M78) and input I94, read into Q0. The listing reads IDX13 [inconsistent with I94 as printed].
```
0 BEGIN PGM TEILEN MM
1 L M79
2 LBL 1
3 FN 18: SYSREAD Q0 = ID2000 NR20 IDX13
4 FN 10: IF +Q0 NE +1 GOTO LBL 1
5 L M78
6 END PGM TEILEN MM
```

## 4.8 Machine parameters

### 4.8.1 General information (p. 72)

The machine parameters adapt the iTNC 530 to the machine. Some are open to the operator. A machine-specific parameter list comes with each machine's documentation.

### 4.8.2 User parameters (p. 72)

- They set the behaviour of the control, data transfer, control characters, the 3D probe, the display, programming and hardware. They are described in the HEIDENHAIN user's manual (conversational), chapter 13.
- To open: PROGRAMMING AND EDITING mode → MOD → code **123** → ENT. Leave with END BLOCK.
- Change parameters right after power-on, because some changes cause a hot start (control reset). Changing an MP generates an EMERGENCY STOP.
- Do not change: **MP6160, MP6560, MP7261.X, MP7440, MP7640, MP7641, MP7645.X**. MP7260 must be ≥ MP7261.

### 4.8.3 Machine-specific user parameters (p. 73)

- They set the control behaviour, programming, DNC mode, tool table, active NC axes, axis behaviour, axis positioning during manual tool change, and options. Every change generates an EMERGENCY STOP, and some cause a hot start.
- Caution: switch the drives OFF before changing a user parameter, with pilot lamp H171 ON. Otherwise the **Z axis may drop**.
- Open: programming mode → MOD → soft key "USER PARAMETERS". Select with the cursor, type the value, press END. The END soft key leaves.

|---|---|---|
| PROGRAM. PLACE ON | 2 (0) | 0 |

#### 4.8.3.1 Description of the user parameters (p. 74; continued in pp. 75+)

- **PROG. STATION ON :2 (0):** 0 = machine control active. 2 = programming station (machine control off). Changing it resets the control.
- **DNC MODE EXT.1 / EXE.2 :1 (0):** 0 = standard data interface. 1 = block-by-block transfer for programs larger than memory or the maximum length.
- **TOOL TABLE: 1-MAX:** number of tools managed, 1-65535 (see "4.6.1 2 tool change" as printed).
  - Note: with the TC on, the tool table must be at least as large as the magazine pocket count. Resizing it may erase tool data.
- **NC AXES: %V, IV, Z, Y, X:** bit mask, 1 = axis active. Example for X, Y, Z only: `%000000111`. Changing it resets the control.
  - Note: the tool changer works only if Y and Z are active.

## For the retrofit

- **C-axis pivot (kinematics):** cycle 307 measures the C-axis turning point. The example log gives Y ≈ 243.885, Z ≈ -50.58, X ≈ -51x.404 [uncertain digits], in machine coordinates. The persistent value is in **MP 950** (used after a reboot), so read MP950 and `TNC:\Cycle_307\List-RP.A` from the old control before decommissioning. Pivot drift is about 0.1-2 µm per run, and the tolerance limit is 0.07 [mm].
- **4th/5th axis clamps:** M10/M11 (4th) and M15/M16 (5th) clamp the axis and open the position loop. The PLC unclamps before each move and reclamps in position. LinuxCNC needs the same sequence: unclamp → wait for the pressure switch → enable the loop. Pressure switches are in the next file's error list.
- **Spindle (original drive kept):** M3/M4/M5/M19 orientation (0° or cycle 13 angle, direction M3 or M4 per user parameter). Warm-up is M302 (temperature-gradient based) or M300 (3 min). The vibration sensor / APS warranty logging is a PLC/iTNC feature that will be lost.
- **Coolant/aux outputs the control switches:** MQL (M7), emulsion (M8), through-spindle coolant (M28), blow-out (M31/M32, also automatically with each tool call), chip conveyor (M35/36), oil-mist extraction (M37/38), graphite extraction (M39/40), central lube pulse (M55), standby that switches off hydraulics/fans/lamp (M77).
- **Spare outputs:** O29 = A500/X510-24, O30 = A500/X510-31, 2 A via relay board 958.74.509. They are not reset by E-STOP. Indexer feedback example: input I94.
- **Safety-relevant:** a parameter change triggers E-STOP. The Z axis can drop if parameters are changed with drives on, so Z has a holding brake / gravity load to handle in the new drive config. Restarting after standby/E-STOP uses POWER ON/OFF S/H171. NC-START is S520.
- **Axis enable mask** order: V (C), IV (A), Z, Y, X. The tool changer needs Y and Z active.
- **Machine parameters not to touch** (useful for knowing what the old configuration relied on): MP6160, MP6560, MP7260/7261.X, MP7440, MP7640, MP7641, MP7645.X. MP960.x is mentioned in the next file (tool-change position). A full MP backup from the iTNC is advised.
- **Thermal compensation (ITC):** X/Y/Z thermal compensation with PT100 probes (see the next file's messages 82-85). It is lost unless reimplemented.
