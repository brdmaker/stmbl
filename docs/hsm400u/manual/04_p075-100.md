## 4.8.3.1 Description of the user parameters (continued, pp. 75-76)

- **LAG MODE :0 (1):** 0 = operation with servo lag, 1 = with velocity feedforward. With lag, the surface on digitized parts is better, but an accurate axis stop is no longer possible.
- **AXES POS. TC MANUAL V:** sets how the axes move for a manual tool change. One digit per axis in order 5 4 Z Y X. 0 = not positioned, 1-5 = priority 1st-5th.
  - Example: Z first, then X and Y together, 4th/5th not moved → input `122` ("corresponds to the standard value").
  - Caution: use only priorities 0-5.
  - Note: "In standard the following value is programmed: **120**" (contradicts the "122" above, as printed).
- **TOOL CHANGER ON: 1(0):** 0 = TC off, 1 = TC on. With the TC off, position monitoring of the changer arm stays active.
- **SENSE OF ROTATION M19 = M4 : 1 (0):** spindle direction during orientation. 0 = as M3, 1 = as M4.
- **ROBOT ON : 1 (0):** 0 = workpiece changer off, 1 = on. With the WPC off, NC programs may not call pallets, but home-position monitoring of the WPC stays active.

## 4.9 Messages of the control (COU) (p. 77)

The control shows NC messages and PLC messages. PLC messages start with a two-digit number. Some more messages appear when CE is pressed.

### 4.9.1 Error diagnosis, procedure

- NC errors are explained in the HEIDENHAIN user's manual and PLC errors in table 4.9.4. If unresolved, contact Mikron after-sales.
- HELP key: the iTNC 530 opens a window with the cause and the remedy.
- Before calling Mikron, have ready: machine type, serial number (machine file, MP list), control type, NC and PLC software numbers, error number, a description (procedure, operation, mode), and the NC program if possible.

### 4.9.2 NC messages

- **4.9.2.1 Severe errors** (blinking), e.g. faults in the measuring systems, drives or data processing. They force a control reset, so the machine must be restarted after the fix.
- **4.9.2.2 Harmless errors**, e.g. input or logic errors, contours that cannot be executed, misuse of the probe. Clear with CE after fixing. HELP opens a help window.

### 4.9.3 PLC messages (p. 78)

- **4.9.3.1 PLC window:** a dialogue window at the bottom of the screen guides the operator. With no message active, it shows milling-spindle utilization.
- **4.9.3.2 Messages 00-29:** severe, trigger EMERGENCY STOP. Clear with CE after fixing.
- **4.9.3.3 Messages 30-49:** internal NC STOP. Clear with CE.
- **4.9.3.4 Messages 50-99:** operation messages. Some can be cleared with CE.

## 4.10 Tool change

### 4.10.1 General information about changing tools (p. 88)

- The central tool memory is always active. Tool data (name, length, radius, edge life, …) live in the tool table and magazine assignments in the pocket table. TOOL DEF L.. R.. in the NC program is not allowed.
- Tool kinds: automatic tools in the magazine (P1 … P18 or P36/68), external tools inserted by hand, and T0 = the empty "blank" spindle tool.

| TC status | Position table | Tool number | Tool change |
|---|---|---|---|
| OFF | No tool allocation | 0 .. 65535 | manual |
| ON | P1 .. P18 or P36/68 | Tool exists in tool table | automatic |
| ON | P1 .. P18 or P36/68 | Tool not in tool table | manual |

- Dialogues guide manual changes and TC resets.
- TC on/off: user parameter TOOL CHANGER ON (0 = off, 1 = on), e.g. when a large workpiece blocks automatic changes. With the TC off, called tools must not be in the pocket table.
- Caution: after changing the parameter, check the pocket table. The magazine drive and magazine switch **S645** stay active with the TC off.
- Warning: never exceed the tool maker's maximum speed. Tools must be balanced to quality **G2.5** per VDI 2060 or ISO 1940 (printed "VDO 2060").

### 4.10.2 Managing the tools: automatic tool call (p. 89)

- The tool memory is TOOL.T, set at the factory to a maximum of **254 tools**. The size is set by user parameter.
- Caution: the operator must keep the magazine and the pocket table consistent and check both before using the changer.
- **TOOL DEF n** pre-positions the next magazine tool to the pick-up position. It is of no speed benefit on this machine.
- **TOOL CALL** does the automatic or manual change and updates the tool data. Syntax: `TOOL CALL [0...65535] [X...IV] S[] F[] DL[] DR[]` or `TOOL CALL "DRILL12" …` (names from the NAME column).
- TOOL CALL 0 empties the spindle.
- After a change, spindle start and coolant must be reprogrammed.
- If the same tool is called again, the spindle and coolant are not stopped.
- Every TOOL CALL does a coolant-emulsion blow-out.
- Tool data activate on a TOOL CALL in MDI positioning, single block and full sequence.

### 4.10.4 Manual tool change (pp. 92-93)

Used when the TC is off, or for tools not in the pocket table. TOOL CALL positions the axes and orients the spindle in an order set by machine parameters, which a user parameter can change.

Standard sequence:
1. Z moves to the manual tool-change position (Z+).
2. Y moves to the tool-change position (Y+).
3. The doors are released. When lamp S/H171 lights, open the doors. Message "72 TOOL CHANGE IN ACTION" shows OLD TOOL / NEW TOOL. The example screen shows X +11.075, Y -319.360, Z +460.045.
4. Release the tool in the spindle taper with tool-retention key **S460**.
5. Clean the spindle and tool tapers. Lightly grease the taper with graphite paste (Molykote HSC, Molykote G-n or Molykote G-Rapid spray). Repeat this often during long roughing.
6. Hold the new tool and keep it pushed in after releasing S460 until clamping finishes. Otherwise the collet chuck can be damaged.
7. Close the doors and press POWER ON/OFF (S/H171). When the doors are locked, NC START (S520) completes the change and the program continues.

- Warning: move Z out of the collision area before the tool call. Changing the positioning order raises the collision risk.
- Warning: tool-change positions (machine zero based) ignore the traverse-range limits. The user must not change **MP960.x**.
- Warning: wear protective gloves when loading or unloading the magazine.

### 4.10.5 Automatic tool change (p. 94)

- Used for tools in the pocket table when the TC is on.
- Sequence: Z moves out of the workpiece (Z+) to the top change position while Y moves to the tool-change position at the same time. Message 72 is shown.
- Warning: put Z at a safe height in the NC program before and after the change.

### 4.10.6 Tool magazine (pp. 94-95)

- The magazine holds the automatic tools. Technical data are in chapter 9.2.1.
- Note: observe the limits in the milling-spindle manual.
- **Clocking:** with the drives on and the loading door closed, rotary switch (1) steps the magazine CW. A tap moves one position. Holding it rotates continuously until release and stops at the next position. This works during a running program but is barred during an automatic tool call.
- **EMERGENCY STOP key (2)** at the magazine works in every mode. At standstill the protection door unlocks (chapter 4.2.1).
- Fig.: magazine operator panel with switch (1) and E-STOP (2).

### 4.10.7 Loading the magazine (pp. 96-97)

- HSK-40 tools have no orientation features and can go in any way.
- Note: put the 3-D touch probe only in **outer** magazine grippers, with the spring pin (probe battery) to the front, within about ±30°.
- Respect the maximum tool size and weight (chapter 9.2). Tool data and magazine assignment must match.
- Warning: tool-data changes during a running program take effect only at the next TOOL CALL.
- Close the loading door after loading.
- Caution: badly seated tools can collide with machine parts.
- Warning: wear gloves, because of cutting and piercing injuries.
- Pocket assignment: enter L, R, etc. in the tool table and the pocket in the pocket table.
- Fig.: magazine with a ring of grippers, and a gripper detail with the probe orientation angle.

### 4.10.8 Recovering the tool changer (TC) (p. 98)

- If the TC was interrupted or is not at home, troubleshooting mode lets the change cycle finish. Logic monitors the axis positions continuously.
- Typical causes: E-STOP during a TC motion, or power off before the TC finished.
- Release mode needs the loading door closed and the work-area door closed and locked.

### 4.10.9 Procedure after a failure (p. 98)

1. Remove any tool still in the spindle by hand.
2. Put it in its correct magazine position.
3. Check the magazine assignment and the pocket table (warning).
4. In MDI, run a TOOL CALL, e.g. `TOOL CALL 5 Z S500`, so the tool, its data and the speed are consistent.
5. Resume the program.

### 4.10.10 Set-up functions of the tool changer (TC) (p. 99)

- Individual TC moves can be run from the machine keyboard (Variant I) or the optional HR 336 handwheel (Variant II). For service and TC checks only.
- Select with an axis key, then run with the left or right arrow:

| Select | Screen | ← | → |
|---|---|---|---|
| +IV | 92 TC RETENTION <- open clos. -> | Close tool retention (clamped) | Open (released) |
| +V | 91 TC DOOR <-OPEN CLOS.-> | Close door | Open door |
| +IV (as printed) | 95 MAG. POSITION <-CW CCW-> | Magazine CW | Magazine CCW |

- The text after "<-" is what the left key does. The text before "->" is what the right key does. (The table rows above follow the printed "Effect" column, which reads in the opposite order from the screen text.)

## 4.11 Workpiece changer (WPC) (p. 100)

- WPC on/off with user parameter Robot ON (0 = off, 1 = on), see chapter 4.7.3.1 [as printed]. With it off, pallets cannot be called but home monitoring stays active.
- **Cycle 320** automatic pallet call. Pallet number 0 - max. Only **7 pallet positions**. Pallet 0 empties the chuck without loading a new pallet. **Chuck number must always be 2**, because the machine has no other clamping.
- A Heidenhain pallet table can be used instead (chapter 4 or the Heidenhain manual, NC 280 476 or later, "pallet management" / "execution of pallet tables").
- With the loading door closed, the pallet magazine can be cycled CW, also during a program, but not during an automatic pallet change. With the door open it can be turned by hand.
- To load pallets, seat the orientation pin under the pallet in its positioning hole.
- Warning: wrongly loaded pallets can collide with machine parts.

## For the retrofit

- **PLC I/O map (partial) from the error table.** Useful for wiring a LinuxCNC HAL/classicladder replacement:
  - E-STOP I0. 5th-axis HW limit I4. Aux motor protection I5. Door open I6. Safety RESET I7. Safety component off I26. Safety switches S/Y161-165, safety component A121.
  - Drives ready I14. Drive over-temperature I15. Load break switch F221. PLC-ready output O31.
  - 4th axis clamp/unclamp pressure switches I16/I28. 5th axis I17/I29.
  - Spindle: tool sensors B208 (I149), B209 (I150), analogue tool retention monitor B460. Spindle lube air I11, pressure switch A425/S1 (I9), lube level I10.
  - Cooling: spindle cooling flow B426 (I147), temperature sensor B304, motor cooling flow I1.
  - Central lube: level I3, pressure I12.
  - Coolant: through-spindle pump Q429 (I67), production package A412/K6 (I66), conveyor Q471 (I68).
  - Magazine: tool present B611 (I19), tool monitoring B630 (I20), B644 (I19, conflicting), magazine tool I137, loading door I23, magazine switch S645.
  - Keys: retention S460, coolant S411, robot key S172, POWER S/H171, NC START S520, S300 on board A500 (limit-switch override).
- **Drive interface:** the old drives give "ready" (I14) and "over-temperature" (I15) to the PLC, and E-STOP 02 says wait 30 s after power-off. stmbl drives must give equivalent ready/fault signals into the E-STOP chain.
- **Rotary axes:** A (IV) and C (V) are hydraulically clamped with pressure-switch feedback and a timeout. Both must be at 0° before being switched off (`L C+0 / L A+0 R0 M91`). The 5th-axis tool-change position must lie between 0° and the + soft limit. The 5th axis has a hardware limit switch (I4) with an override key S300 on A500. The manual's IV/V axis letters are inconsistent (24 positions "C" for IV, 25 positions "A" for V), so check the real mapping on the machine.
- **Spindle (original drive kept):** speed-reached timeout (07), orientation timeout (16), speed monitoring (33), overload (28), I²t (39), motor over-temperature (37/86, restart after a 20-degree drop). Spindle cold warm-up limits speed to 3000 rpm and locks feed until 20 °C (77). Pre-lube blocks the start for up to 10 min (47/79). Spindle cooling flow/temperature also gate operation. The new control must replicate these interlocks or take them from the spindle drive.
- **Tool changer sequence:** TOOL CALL → Z+ to the top change position while Y moves into the change area (Y+) → spindle orient (M19 direction set by user parameter) → magazine/arm exchange. Tool-change positions come from **MP960.x** (machine-zero based, outside the soft limits), so read them from the old control. The Y slide in the TC area is monitored (17). HSK-40 tools in the magazine (HSK63 mentioned for other spindles). Magazine P1-P18 or P36/68 pockets. The drawbar is hydraulic with a timeout (13) and the retention is monitored by B460.
- **Lubrication/cooling the control switches:** central lube pulses with pressure monitoring (2 on/off cycles), spindle oil-air lube with air pressure and level, motor and spindle cooling circuits with flow switches, PT100-based heat compensation for Y/Z (EWK/ITC). Code 4261 shows the spindle cooling temperature.
- **Servo mode:** LAG MODE 0 = following error, 1 = velocity feedforward. Use feedforward on stmbl/LinuxCNC.
- **WPC/robot (if fitted):** 7 pallet positions, chuck 2, cycle 320/321, Erowa JMS option, WPC loading door and robot ready interlocks.
