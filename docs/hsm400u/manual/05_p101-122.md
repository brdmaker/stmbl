## 4.11.1 Workpiece changer recovery

- If a WPC cycle is interrupted or the WPC is not at home position, WPC recovery mode is activated; the change cycle is completed by driving the WPC back home with recovery functions, then machining can resume.
- The recovery logic continuously supervises axis positions and activates recovery mode if needed.
- Typical causes: E-STOP pressed while WPC running; machine switched off (power interruption) before WPC finished; a defective proximity switch; magazine cannot be positioned; compressed air < 5 bar.
- Recovery via the operating panel (OP) keyboard or the extended handwheel HR366 (spelled HR336 on p.102 [uncertain which]). Depending on axis and magazine positions the operator answers dialog questions so the PLC can determine the recovery sequence.
- Recovery mode only activates if: one of the above causes occurred; WPC loading door closed; cabin door to work area closed and locked.
- Warning: motions are only partially monitored; wrongly triggered motions can cause collisions.

## 4.11.2 WPC recovery functions

Axis keys -IV, +IV, -V, +V select a function and cursor left/right execute it while recovery mode is active. Variant I: machine keyboard; Variant II: handwheel HR336 (option).

| Select key | Message on screen | Execute | Effect |
|---|---|---|---|
| +IV | 52 WPC LINEAR AXIS <- GR MA -> | left / right | Home position / Machine position |
| -IV | 53 WPC ROTARY AXIS <-CW CCW-> | left / right | Clockwise / Counter-clockwise |
| -V | 54 WPC CHUCK <- OP / CL -> | left / right | Open chuck / Close chuck |
| +V | 55 WPC LIFT <- UP / DOWN-> | left / right | Vertical up / Vertical down |

Text after "<-" is the left-cursor function, text before "->" the right-cursor function.

Procedure:
1. Hold the select key (light grey); the dialog text appears (e.g. "52 WPC LINEAR AXIS <- GR MA->").
2. Additionally press an execute key (dark grey); motion runs only while both keys are held.
3. Step the WPC back to home; at home "56 WPC RECOVERING END -> NC-START" is shown.
4. Press NC-start to exit recovery mode.

Rectification of pallet data (cycle 321), after recovery:
1. If a pallet is still in the gripper, bring it to its magazine position using recovery mode.
2. Use cycle 321 to assign which pallet is currently in the work-area clamping chuck.
- For pallet tables see Heidenhain user's manual (NC 280 476 or higher), chapter 4, "pallet management" / "execution of pallet tables".

## 4.13 Milling and measuring cycles

- 4.13.1 Rigid tapping (cycle 17): standard. If NC stop, spindle-stop or power ON/OFF is pressed during tapping, TNC shows soft key "MANUAL TRAVERSE"; after pressing it the tap can be driven free in NC-controlled mode with the positive axis direction key (printed "Z-" [uncertain]). See HEIDENHAIN conversational manual ch. 8.
- 4.13.2 Thread cutting (cycle 18): a spindle start (traversing the spindle reference point) must have occurred before calling; approach/retract moves must be in the NC program.
- 4.13.3 Boring (cycle 202): standard.
- 4.13.4 Blum laser tool measurement: contactless, rotating or stationary, per cutting edge. Visible laser class 2, 670 nm, output < 1 mW. Each measurement runs "coolant blow-out". Cycles per Blum programming instructions.
- Warning: cycle 580 must never be programmed by the user; only for initial setup/adjustment of the Blum laser at commissioning.
- Laser rules: avoid visual contact; do not look into beam even with optics/mirrors; no hands in beam; avoid direct skin exposure. Non-compliance: permanent eye damage, skin burns.

## 5. Servicing and Maintenance

Covers measures to maintain/restore optimal state; Mikron offers maintenance courses (see 1.2).

### 5.1 Safety instructions

- Servicing only by instructed, trained specialists; customer monitors qualifications.
- Staff must have read the documentation first.
- Make pneumatic, hydraulic, cooling and electrical systems safe before work (disconnect mains, depressurize).
- Main switch Q111 (see 4.2.3) off and secured against switch-on before servicing.
- If diagnostics via CNC/PLC are needed with power on, set load switch F221 to OFF and secure it.
- Warning: after switch-off the regenerative capacitors stay at dangerous voltage approx. 4 minutes; during standstill in position control loop, elements can be live; work on electrics only with main switch off and secured (risk of death by electrocution).

### 5.2 Operating media and equipment

- Media: lubricating oil, hydraulic oil, cooling lubricant, air. Poor lubrication shortens roller bearing and ballscrew guide life.
- Lube point marking per DIN 8659; fluid lubricants per DIN 51519 (ISO viscosity class at 40 °C).

#### 5.2.3 Central lubrication

- Warning: switch machine off when working on the pump; the motor restarts after an interval and the propeller can catch a hand.
- Pump needs no special maintenance. Top up oil after approx. 200 operating hours or as required; check tank once a year for sludge on tank floor and residue on filter.
- Cleaning if contaminated:
  1. Remove protective cover, slacken the eight socket head cap screws, remove tank.
  2. Release filter carefully, pull up brass ring, unscrew.
  3. Clean tank and filter with petroleum ether or petroleum; dry with lint-free cloth. No benzene, acetone or fluids with softeners.
  4. Screw filter back, press down brass ring (do not jam), refit tank and cover; if it will not fit, check filter is screwed in.
- Caution: never remove the filter or pierce it; particles damage the pump.
- Pump (Vogel "Zentralschmierung"): plastic tank 2.7 l, delivery 0.1 l/min, max 25 bar, 230 V 50/60 Hz; pressure switch, level switch, terminal strip, push button; charging hole. Spare: oil strainer 954.82.10.901.
- Operation: lubrication pulse after a time set in machine parameters and after a specific distance travelled.
- Faults: (a) oil level low -> "63 CHECK CENTRAL LUBRICATION", deletable, machine keeps running. (b) lubrication level/pressure not achieved -> "63 CHECK CENTRAL LUBRICATION", current program may finish; if pressure not reached a second time -> "31 CENTRAL LUBRICATION FAULTY"; resume by acknowledging.

#### 5.2.4 Spindle lubrication

- Oil/air unit with a pump identical to the central lube pump (manual refers to "Section 6.2.3.1" for safety/maintenance [likely means 5.2.3]).
- Faults: (a) oil below fill level -> "78 CHECK SPINDLE LUBRICATION" (deletable). (b) lube pressure not reached -> rapid stop, "38 ERROR SPINDLE LUBRICATION"; spindle cannot restart until pressure restored. (c) pneumatic pressure gauge responds -> rapid stop and spindle stop, "38 ERROR SPINDLE LUBRICATION"; spindle blocked.

##### 5.2.4.1 Cutting oils

- Machines are designed for water-mixed coolant emulsions, not cutting oils (see ch. 10.2).
- Warning: do not inhale oil mist/vapour. Avoid by: adequate coolant supply at the cut; choose viscosity (low = cools better, vaporises more; high = cools less, vaporises less); check fill regularly (full tank lowers oil temperature); oil with more additives to reduce friction heat; low-misting oil.

##### 5.2.5.3 Hydraulic aggregate

Fig. (HSM 400 and HSM 400U variants): 1 pressure switch/manometer, 2 choke valve, 3 filler screw with integrated air filter, 4 pump motor M421, 5 pressure regulation valve, 6 way valve Y461, 7 nitrogen accumulator, 8 gear pump, 9 oil suction filter, 10 oil inspection glass, 11 oil drain screw. The 400U unit carries the extra valve block.

- Maintain only with machine off and pressure reduced. Little maintenance, but essential.
- Monitor oil level and temperature (temperature rise indicates contamination); visual check at inspection glass.

| Problem | Contamination | Possible cause | Action |
|---|---|---|---|
| Dark discoloration | oxidation products | overheating, oil not changed (incompatible oil) | change oil |
| Milky cloudiness | water or foam | ingress of water/air | change oil |
| Air bubbles | air | air ingress, low oil, leaking suction line | top up oil, bleed pipes |
| Suspended/deposited impurities | solid particles | friction, dirt, ageing | change oil, possibly replace unit |
| Burnt smell | ageing products | overheating | change oil, possibly replace unit |

- Change fluid if contaminated before the scheduled interval.
- Changing hydraulic fluid:
  1. Remove any tool from the spindle, switch machine OFF.
  2. With machine off, press the manual actuator of way valve Y426 (as printed) repeatedly until the circuit is depressurized.
  3. Drain tank via oil drain screw (12, as printed; legend no. 11).
  4. Refill via filler screw (3), max. 10 l (as printed). Oil: Mobil DTE 24 (see 5.3.2).
- Filters: most premature failures come from contaminated fluid; check oil/air filters per lubrication schedule; replace air filter (3) depending on environment.
- Warning: reservoir (accumulator) under pressure (100 bar).

#### 5.2.6 Cooling unit (CU)

- Initial fill: delivered empty; fill at commissioning with 5.0 % Coolant-F in drinking-quality water (ratio strictly); add SWISSCARE ANTISEPT (supplied quantity).
- Weekly: check coolant level and air filter for soiling.
- Refill when below MIN up to MAX: remove silver tank lid through opening at rear of covering hood; fill with funnel/hose; close cap.
- Caution: after every refill verify mixture with a refractometer.
- Filter replacement: remove filter grid at front with screwdriver, insert new mat, refit. Genuine mats from Mikron spare parts.
- Warning: never run the cooling unit without filter or without coolant.
- Yearly: add 3 % SWISSCARE SC system cleaner 3 days before change (machine may run normally), then drain, clean, refill with exactly 5 % Coolant-F in clean tap water.
- Spindle cooling errors: over-temperature -> "48 EXCESS TEMPERATURE SPINDLE"; insufficient flow -> "46 ERROR SPINDLE COOLANT" (check coolant level).

##### 5.2.8.4 Air maintenance unit

- No pressure in the unit during maintenance.
- Bowls: unscrew plastic container (1) anticlockwise; clean only with water, petroleum or petroleum ether (no benzene, acetone, softener-containing fluids).
- Sintered bronze cartridge (3): remove by unscrewing pressure washer, wash in petroleum ether/petroleum, blow dry from inside out; replace if heavily soiled.
- Borosilicate fine filter cartridge (4): cannot be cleaned; replace at latest at differential pressure > 1 bar; unscrew anticlockwise.
- Spares: fine-pore filter white, main supply 820.00.00.054; fine-pore filter green, barrier air 820.00.00.055.

## For the retrofit

- E-STOP / safety: main switch Q111, load switch F221 (drive power) used to disable drives for diagnostics; regen capacitors stay live ~4 min after switch-off.
- WPC recovery logic is PLC-side (messages 52-56, needs WPC loading door closed and cabin door locked, air > 5 bar); with LinuxCNC the WPC sequence, recovery jog functions and pallet tracking (cycle 321 equivalent) must be reimplemented in HAL/ladder or Python.
- Central lubrication: PLC pulses by time (machine parameter) and by distance travelled; inputs pressure switch + level switch; messages 63 (warning) and 31 (fault after second missed pressure). Pump 230 V 50/60 Hz, 25 bar.
- Spindle oil/air lube: valve Y405, pressure switch S425, level switch; missing pressure must trigger rapid stop and spindle inhibit (msg 38).
- Spindle cooling unit: over-temperature (msg 48) and flow (msg 46) signals must interlock the spindle.
- Hydraulics: pump motor M421 (0.37/0.44 kW, 400 V); valves Y461 (tool clamp/unclamp, spindle), -B426 15 bar and -S343 110/95 bar pressure switches, 70 bar accumulator. HSM 400U: rotary-table clamp valves Y341 (C) and Y351 (tilt axis), each clamp monitored by 35 bar and 5 bar pressure switches (handwritten B442/B443); LinuxCNC must clamp/unclamp A/C and check these switches before/after rotary moves. All solenoids 24 V DC.
- Tool clamp pressure depends on spindle type (Table X): identify the installed HVC spindle.
- Pneumatic valves the control switches: Y404, Y405, Y406, Y424, Y425, Y427, Y428, Y444, Y601/Y602; spindle barrier air 4 bar and measuring-system (glass scale) barrier air 0.5 bar must stay on whenever powered.
- Blum laser: shutter Y427, barrier air Y428, coolant blow-out per measurement; Blum cycles (and setup cycle 580) are Heidenhain cycles that need replacement.
- Rigid tapping (cycle 17) and thread cutting (cycle 18) need spindle position/encoder feedback and spindle reference; LinuxCNC needs spindle encoder from the kept spindle drive.
- Operating-hour counters (control, machine, program, drives, spindle) are in the TNC; note values before removing it.
