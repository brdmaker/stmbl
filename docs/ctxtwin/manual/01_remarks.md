## 1.1 Who is this documentation intended for?

The Gildemeister CNC lathe is a robust, high capacity machine with a high standard of technology, requiring thorough care and maintenance.

This documentation is addressed to:

- **Service technicians of the manufacturer or sales agency**
- **Maintenance personnel of the customer,**

who perform the following tasks:

- conducting maintenance and service at regular intervals
- ordering and installing component parts, or wear parts
- repair and installation work, e.g. after collisions

## 1.2 What is the purpose of this documentation?

This manual supplies the service technician with all information required to order spare parts and for the repair.

It is arranged according to assembly groups and describes each assembly group with illustration and technical data, if necessary, function, operation, maintenance and repair.

## 1.3 What is not contained in this documentation?

Neither the standard operation nor the machine programming is described in this documentation (for this purpose refer to the operating instructions and programming manual). For information concerning the electrics, refer to the Electrical Technical Documentation.

**Information**

If you would like further information or if particular problems occur which are not explained comprehensively enough in this documentation, please ask your Gildemeister agency for the required information.

Warning (warning-triangle symbol): **Make absolutely sure that the safety regulations and precautionary measures shown in chapter 0 and 3 are observed!**

**All rights reserved for modifications serving technical progress.**
