## 5. Operation of the machine and controls (page 5-3)

If you are not yet familiar with the machine this chapter is particularly important for you.

The operation of machine and controls is explained here, encompassing:

- Work to be carried out prior to switching on.
- Switching the machine on and off
- The acknowledgement of faults and messages (How are fault message erased from the screen?)
- Operating field and keyboard (Where do I find which keys?)

## 5.1 General instructions (page 5-4)

### 5.1.1 Modular groups

The controls receive 2 modular groups in accordance with the machine concept, termed **AG** in the following.

- each AG is autonomous as far as its operating and programming surface is concerned
- an AG can include several spindles and several slides
- each AG deals with its own working space
- only one operating mode exists at the same time in an AG
- differing operating modes can simultaneously exist in both AG, i.e. operating mode splitting
- with full utilisation of operating mode splitting it is necessary that the working spaces be divided by a separating wall for safety reasons.

### 5.1.2 Operating mode splitting

The operating mode splitting can be switched on and off via a parameter switch:

- in the operating mode splitting ON the effect of the cycle start, cycle stop, and feed stop keys is dependent upon the setting of the **AG** selector switch.
- In the operating mode splitting OFF mode the buttons cycle start, cycle stop, and feed stop keys simultaneously affect both **AG.**

## 5.2 Operating elements and keyboard (page 5-5)

This section briefly explains the location of individual operating elements on the machine and their functions (see illustration of following page).

### 5.2.1 Operating elements on the right hand side

Figure: right-hand end of the machine (electrical cabinet side) with callouts 1-5: (1) operating hours counter on the cabinet door, (2) main switch (rotary), (3) motor protection switch for chip conveyor (below the main switch), (4) pressure gauge (round gauge on the hydraulic unit panel above a ventilation grille), (5) coolant filling level sight glass (top).

1. **Operating hours counter**
   The operating hours counter indicates how many hours the machine has been in operation in total (important for regular maintenance work).
2. **Main switch**
   You can switch the machine on and off using the main switch.
3. **Motor protection switch for chip conveyor**
   If the chip conveyor is overloaded this switch is automatically triggered, e.g. in the event of a chip jam. Following this overcome the fault causing the triggering and switch on again.
4. **Pressure gauge**
   This pressure gauge indicates the system pressure of the hydraulic system.
5. **Coolant filling level**
   This inspection glass indicates the coolant container level for the spindle motors.

### 5.2.3 Further operating elements (page 5-20)

**(1) Manual protection hood release**
The protection hood can be manually released through this opening using a screwdriver or similar, provided the machine electrical supply is turned off.

**(2) Data transfer interface**
You can connect external data carriers to this serial interface, e.g. personal computer or printer. For operating an external data memory an additional 230 V / 150 W / 1 A receptacle is fitted.

**(3) Foot switch for chuck actuation**
Serves for clamping (right hand pedal) and releasing (left hand pedal) the chuck. The left hand pedal is the allocated to the AG 1, the right hand to AG 2.
The right hand pedal is always assigned "Clamp chuck" and the left hand pedal always "Release chuck" - irrespective of whether internal or external chucking is performed.

**(4) Chucking pressure setting**
Chucking pressure is set by the handwheel.
The pressure reduction valve is activated using a spanner.
The left hand chucking unit is allocated to AG 1, the right hand to AG 2.

## 5.3 Menu techniques and softkeys (page 5-21)

(Heading in the text: "Menu techniques and softkeys"; contents list: "Menu technique and softkeys".)

During operation you are guided by the controls.
The screen displays **menus**, from which you can select the options offered.

To make your selection, use the **softkeys**.
The word softkey is a combination of the words software and key (program and key). They are termed softkeys because they have no specific "hard" function.

Their function is dependent upon the menu on the screen.

The Gildemeister Eltropilot controls use the digit keys 1 to 9 as softkeys.

In each case you enter the digit of the digit keyboard, which is at the required menu position.

For example, select the MACHINE control operating mode by pressing the digit key 7.

At positions where you have to press a softkey, we will use the expression ***"select"*** in the operating instructions, e.g.

select `MACHINE`

or

select menu point `REFERENCE AUTOMATIC`.

## 5.7 Switching the machine on and off (page 5-35)

Check the oil levels in advance and top up if necessary, refer to 8.2, "Oil levels, control" on page 8-3.

### 5.7.1 Switching on the machine

The following steps are necessary to switch the machine on:

- If necessary, release the emergency stop key by turning clockwise
- Turn the main switch in the switch cabinet to setting 1.
- ✓ The operating hour counter now runs and the machine lighting is switched on.
- Press the "Machine (Drives) on" key on the operating panel. (motor + `I` symbol)
- ✓ The message `press operating mode key` appears after approx. 1 minute.
- Open the protection hood
- Close the protection hood
- ✓ The protection hood function is now tested and all functions are released
- Press the key (operating modes key)
- ✓ The current date in the screen top right is highlighted in red. This means that a fault is pending which must be overcome.
- Press the "FAULT STATUS" key
- ✓ The following fault messages appear most frequently: `Fault display: Tool holder not locked in position`.
- Press the <<ESC>> key to close the fault window
- Select the MACHINE operating mode
- Select the `T` menu point
- Select the `T DIRECT` menu point
- Select a tool from 1-12 and confirm
- Press the <<DEL>> key to cancel the fault message
- ✓ The tool holder is locked. You are in the MACHINE operating mode.

### 5.7.2 Move to reference point (page 5-36)

Following each switching on of the machine move to the reference points, in order to activate the machine measurement system.

To move to the reference point all auxiliary equipment must be in the basic or working position, e.g. the chuck must be fully opened or clamped and the tool holder locked. The protection hood as well as all electrically monitored auxiliary doors must be closed.

The controls can by moved to the reference point in both directions:

For this reason firstly move the slide to a corresponding start position. Proceed as follows:

- Press the key (operating modes key)
- ✓ The screen shows the operating modes.
- Select the operating mode MACHINE.
- ✓ The screen shows the MACHINE menu
- Select the `AUTOMATIC REFERENCE` menu point.
- ✓ You can see a dialog box `STATUS MOVE TO REFERENCE POINT`.
- Confirm.
- ✓ The screen shows the dialog box `AUTOMATIC MOVE TO REFERENCE POINT`. You can select for which slide the reference point is to be moved to (if several slides are present).
- Press the "Cycle start" key.
- ✓ The slide moves to the reference point. On the screen you can see the spacing between tool centre and machine datum in the X and Z display.
- Traverse the slides with the manual control keys to the start point of your automatic program or to a position in which the machine can be set up without interference.

### 5.7.3 Acknowledge fault displays and messages (page 5-37)

If the screen indicates faults or messages, it is possible that these must firstly be acknowledged, prior to you being able to continue working (date highlighted in red).

- Press the "FAULT STATUS" key
- ✓ The fault is displayed.
- If necessary overcome the cause of the fault. A list of the most common faults can be found in the fault message.
- Press the fault key again.
- Erase the fault message with key `Del`
- Close the fault window with "Esc" key

Note (hand symbol): When the cause for a fault cannot be overcome the system does not allow the entry in the fault list to be erased. You are shown a dialog box signalling `Do not erase fault`. This box can be closed again by pressing the "Confirm" key (black acknowledgement key shown).

Try to overcome the cause of the fault again.

### 5.7.4 Move clear of working area limit switch (page 5-38)

(Contents list: "Moving clear of working space limit switch".)

The working area position switches represent an electrical safety device. They prevent the start up of the slides on the machine mechanical end points.

They become effective if the software control was incorrectly not active (e.g. when the operator has not moved to the reference point or the "working space" parameter has not been correctly changed).

If the slide moves to one of these position switches, the machine is automatically switched off. Slide and spindle stop.

The screen shows the fault message, such as:

`Hardware position switch +X actuated -NC not operational`

- Erase the fault message with the key `Del`
- Press the key (operating modes key)
- Select the operating mode MACHINE/MANUAL CONTROL
- ✓ The message `Press the move free key` appears - Move X axis free in plus (minus) direction.
- Open the protection hood and turn the setting mode key switch position. (setting-operation symbol)
- Press the key (agreement key symbol) and a "MANUAL DIRECTION" button.
- ✓ The slide moves free.
- Switch off the setting operation again and close the protection hood.
- ✓ The machine is operational again.

### 5.7.5 Switch off the machine (page 5-39)

Caution (warning symbol): Only switch off the machine when the spindle is stationary. Otherwise machine damage will result.

Caution (warning symbol): Secure the workpiece prior to switching off the clamping energy. After switching off the clamping energy the hydraulic system is without pressure. The danger then exists that the workpiece will be released from the clamping device (chuck, tailstock, steady rest etc.)

When switching the machine off, proceed as follows:

- Turn the main switch on the switch cabinet to setting **0**.
- ✓ The operating hour counter does not count. The screen darkens.

### 5.7.6 Emergency stop cut out

Caution (warning symbol): Only use the emergency stop key when a danger is imminent or as a protection during maintenance and repair work on and in the machine.

You can stop the machine immediately from any operating condition. To this effect press the red Emergency Stop key.

The feed or the high speed and the spindle brake and stop immediately. All moveable units are disconnected from the mains electrically. No machine moving functions are possible.

To restart the machine, release the emergency stop key by turning to the right. Subsequently proceed as described under "Switching on machine", see 5.7.1, "Switching on the machine" on page 5-35.

The main switch need not be switched on again, it is also not necessary to move the axes to the reference points.
