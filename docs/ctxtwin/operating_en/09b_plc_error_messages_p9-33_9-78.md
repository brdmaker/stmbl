Source: `CTX_twin_Operating_instructions_9b.pdf`, 46 pages (scanned), manual pages 9-33 to 9-78. "Operating instructions CTX twin, Dok. No.: daaab1g1, February 1995". Chapter 9 "Parameter setting, M commands, PLC error information".

These pages contain only the PLC error information list. The list **starts before these pages** (part a ends at page 9-32; the section heading, the introduction and messages below 300 are there) and **ends on page 9-78** with message 2750; the rest of page 9-78 is empty. Chapter part c continues after page 9-78. No figures, no blank pages.

Running header on every page: "9. Parameter setting, M commands, PLC error information", with the first message number on the page at the right (e.g. "402 F:"). Footer: "Operating instructions CTX twin", "Dok. No.: daaab1g1, February 1995", "Page 9-xx".

Scan notes:
- PDF page 40 has the footer misprinted as "Page 9-2"; by sequence it is page 9-72 (messages 2102 to 2107).
- Page 9-44: message number 1001 is circled by hand and a hand-drawn arrow points at it; 1850 on page 9-69 is also circled by hand.
- Page header of 9-54 reads "1256 H:" while the message itself is printed "M:"; message 351 is printed "H:". The meaning of the prefix letter "H" is not explained on these pages (F = fault, W = warning, M = message presumably, explained in part a).

## For the retrofit

- I/O system: the PLC talks to "Eltromatic" I/O modules (run-up phases 0, 1, 3, 4, service channel, cyclic communication, module earth connections; 400 to 410, pp. 9-33 to 9-35). Control temperature and NC/PLC interface: NC reaction time to a PLC signal must be under 300 ms (951, p. 9-44). The control make/model is not named on these pages.
- Feed drives use servo "choppers" with a supply module and mains contactor (1450 to 1463, pp. 9-58 to 9-60); slide X and slide Z are named separately, plus an X axis motor ventilator with motor protection switch (1457, 1460, 1461). Secondary drive mains contactor must drop out when the hood is opened (2750, p. 9-78).
- Main spindle: main drive gearing with several positions/stages (450 to 453, 1002); C axis may only be switched on in gearing stage 1 (1801, p. 9-69); C axis has a pressure switch and limit switch (spindle clamping/brake, 1800); main spindle clamping requires spindle in a position window, positioned with the C axis first (700 to 703, p. 9-40). Spindle motor has an auxiliary ventilator with motor protection switch (653/654) and temperature pre-warning (655/656).
- Speed limits: independent rotational speed monitoring unit limits main spindle to 50 rpm in setting mode and 5000 rpm with hood closed (1850, p. 9-69). Chuck has its own maximum speed parameter (601, p. 9-38).
- Main chuck (hydraulic, stroke-controlled): clamping pressure switches per clamping direction, rear and front stroke proximity switches, "useful stroke" setting, clamp/release by M command or foot switch; chuck command inadmissible while spindle turns (602); spindle may not run more than 90 s with chuck open (556); clamp/release cycle must finish within 20 s (559); chuck key in operating panel release switch for change position (600). pp. 9-37 to 9-39.
- Counter spindle (relevant to part transfer): its own clamp with the same monitoring set (pressure loss, rear/front stroke proximity switches, clamping stroke limit, 90 s rule, undefined position, M command or foot switch; 2450 to 2502), its own drive/chopper (2550 to 2556), its own C axis (2600, 2601), a counter spindle cover (2650). Parameters 1032 to 1034. pp. 9-49, 9-74 to 9-77.
- Tool holder/turret: indexed by T command; position generator with parity check (1505), preindexing, lock initiator "Control interlocking" (1510), overload clutch (1511), release and reference traverse time-outs (1512, 1513), signals "disc disengaged"/"spindle disengaged" (1514); T value limited by parameter "Holder number" (1507); T change blocked e.g. with hood open (1508). pp. 9-60 to 9-62.
