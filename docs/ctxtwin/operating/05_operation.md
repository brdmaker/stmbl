If you are not yet very familiar with the machine, this chapter is especially important for you.

The operation of the machine and the control is explained here. This includes:

- work that must be carried out before switching on

## 5.1 General notes (Allgemeine Hinweise) (page 5-4)

### 5.1.1 Unit groups (Aggregategruppen)

In accordance with the machine concept, the control contains 2 unit groups (`Aggregategruppen`), called **AG** below.

- each AG is autonomous on the operating and programming interface
- an AG can contain several spindles and also several slides
- each AG handles its own work area
- in one AG only one operating mode exists at a time
- different operating modes can exist at the same time in the two AGs, i.e. operating mode splitting (`Betriebsarten-Splitting`)
- when operating mode splitting is used fully, separation of the work areas by a partition wall (`Trennwand`) is required for safety reasons.

### 5.1.2 Operating mode splitting (Betriebsartensplitting)

Operating mode splitting can be switched on and off by a parameter switch:

- in the mode operating mode splitting ON (`EIN`) the effect of the keys cycle start / stop (`Zyklus-Start / -Stop`) and feed stop (`Vorschub-Stop`) depends on the position of the selector switch **AG**.
- in the mode operating mode splitting OFF (`AUS`) the keys cycle start / stop and feed stop act on both **AG** simultaneously.

## 5.2 Operating elements and keyboard (Bedienelemente und Tastatur) (page 5-5)

This section explains in short form where the individual operating elements on the machine are and what function they have (see figures on the following page).

### 5.2.1 Operating elements on the right-hand side (Bedienelemente an der rechten Seite)

Figure: right-hand end of the machine / electrical cabinet, with callouts 1-5: (5) sight glass at the top of the cabinet, (4) round gauge on the left part, (1) small counter, (2) round main switch and (3) motor protection switch on the cabinet door; ventilation grille and a sight glass lower left.

1. **`Betriebsstundenzähler`** (operating hours counter): shows how many hours in total the machine has been in operation (important for regular maintenance work).
2. **`Hauptschalter`** (main switch): switches the machine on and off.

4. **`Manometer`** (pressure gauge): shows the system pressure of the hydraulic system.
5. **`Füllstand Kühlmittel`** (coolant level): this sight glass shows the fill level of the coolant tank for the spindle motors.

## 5.3 Menu technique and softkeys (Menütechnik und Softkeytasten) (page 5-21)

You are guided by the control during operation. The screen shows you menus from which you can select.

To select you use the softkeys.
The word softkey is a combination of software and key (program and key). The keys are so called because they do not have a fixed, hard function.

Their function depends on the menu on the screen.

On the Gildemeister **Eltropilot** control the number keys 1 to 9 serve as softkeys.

You enter the digit of the number keypad that stands at the desired menu position.

For example, you select the operating mode `MASCHINE` by pressing number key 7.

Where you have to press a softkey, this operating manual uses the expression ***wählen*** (select); such keys or functions are marked by capital letters, e.g.

`Betriebsart MASCHINE wählen` (select operating mode MACHINE)

or

`Menüpunkt REFERENZ AUTOMATISCH wählen` (select menu item REFERENCE AUTOMATIC).

### 5.7.1 Switching the machine on (Maschine einschalten)

### 5.7.2 Approaching the reference point (Referenzpunkt anfahren) (page 5-36)

After every switch-on of the machine you must approach the reference point. This activates the measuring system of the machine.

For reference-point travel all auxiliary units must be in their home position or working position, e.g. the chuck must be fully open or clamped and the tool turret (`Werkzeugrevolver`) locked. The protective hood and all electrically monitored auxiliary doors (`Nebentüren`) must be closed.

The control can approach the reference point in both directions.

Therefore you must first move the slide to a suitable starting position. Proceed as follows:

- Press the key (operating modes key, 17a).
- √ The screen shows the operating modes.
- Select the operating mode `MASCHINE`.
- √ The screen shows the menu `MASCHINE`.
- Select the menu item `REFERENZ AUTOMATISCH` (reference automatic).
- √ You see a dialog box `STATUS REFERENZPUNKTFAHREN` (status of reference-point travel).
- Confirm.
- √ The screen shows the dialog box `AUTOMATISCHES REFERENZPUNKTFAHREN` (automatic reference-point travel). You can select for which slides you want to approach the reference points (if several slides are present).
- Press the key «`Zyklus Start`» (cycle start).
- √ The slide approaches the reference point. On the screen you see in the X and Z display the respective distance between the tool tip and the machine zero point.
- Move the slides with the manual control keys to the start point of your automatic program, or to a position in which you can set up the machine without obstruction.

### 5.7.3 Acknowledging error displays and messages (Fehleranzeigen und Meldungen quittieren) (page 5-37)

If the screen shows errors or messages, you may have to acknowledge them before you can continue working (red shading of the date).

- Press the «`FEHLERSTATUS`» key.
- √ The errors are displayed.
- Eliminate the cause of the error if necessary. A list of common errors can be found in the chapter error messages (`Fehlermeldungen`).
- Press the error key again.
- Delete the error message with the key `Del`.

### 5.7.4 Moving off the work-area position switches (Arbeitsraum-Positionsschalter freifahren) (page 5-38)

The work-area position switches are an electrical safety device. They prevent the slides from running into the mechanical end positions of the machine.

They come into action when the software monitoring is erroneously not active (e.g. if the operator has not approached the reference point or the parameter "`Arbeitsraum`" (work area) was changed improperly).

If the slide runs onto one of these position switches, the machine is switched off automatically. Slides and spindle stop.

The screen shows an error message such as:

"`Hardware-Positionsschalter +X betätigt - NC: nicht betriebsbereit`" (hardware position switch +X actuated - NC: not ready for operation)

- Delete the error message with the key `Del`.
- Press the key (operating modes key, 17a).
- Select the operating mode `MASCHINE/HANDSTEUERN`.
- √ The message "`Freifahrschlüssel betätigen - X-Achse in Plus (Minus) Richtung freifahren`" (operate the release key - move X axis clear in plus (minus) direction) appears.
- Open the protective hood and turn the key switch to position setup mode (`Einrichtebetrieb`, symbol: filled dot on a base line).
- Press the key (enabling key `Zustimmen`, 7) and a «`HANDRICHTUNGS`» (manual direction) key.
- √ The slide moves clear.
- Switch setup mode off again and close the protective hood.
- √ The machine is ready for operation again.

### 5.7.5 Switching the machine off (Maschine ausschalten) (page 5-39)

Warning (warning symbol): Only switch off the machine when the spindles and axes are stationary. Otherwise machine damage can result.

Warning (warning symbol): Secure the workpiece before switching off the clamping energy. After the clamping energy is switched off, the hydraulics have no pressure. There is then a danger that the workpiece comes loose from the clamping devices (chuck, tailstock, steady rests (`Futter, Reitstock, Lünetten`)).

When you switch off the machine, proceed as follows:

- Set the main switch on the control cabinet to position 0.
- √ The operating hours counter stops. The screen is dark.

### 5.7.6 Emergency-stop shutdown (Not-Aus-Abschaltung)

Warning (warning symbol): Only use the emergency-stop button when there is imminent danger or for safety during maintenance and repair work on and in the machine.

You can stop the machine immediately from any operating state. To do this, press the red emergency-stop button.

This immediately brakes and stops the feed or rapid traverse and the spindle. All movable units are electrically disconnected from the mains. No moving machine function is possible any more.

To put the machine back into operation, you must unlock the emergency-stop button by turning it clockwise. Then proceed as described under switching the machine on, see 5.7.1, "Switching the machine on" on page 5-35.

The main switch does not have to be operated, and no reference travel of the axes is necessary.
