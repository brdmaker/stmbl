## 4.1 Short instructions for the loader (page 4-3)

These "Short instructions for the loader" should be used by trained-on (semi-skilled) staff as a memory aid.

### 4.1.1 Starting the machine (`Maschine starten`)

**Prerequisites:**
- The machine is set up
- the first workpiece has been machined correctly
- the control is in operating mode `MASCHINE / AUTOMATIK` (machine / automatic)

Steps:

- **Select selector switch `AG 1` or `AG 2`, depending on parallel or complete machining.**
- **Insert the part carefully (make sure it seats against the chuck jaws).**
- **Clamp the chuck with the right foot switch (at least 2 seconds).**
- **Close the guard door(s) (`Schutzhaube(n)`).**
  - Wait until the green lamp(s) of the key(s) light up and the enables (`Freigaben`) appear on the screen.
    Figure: key pair symbol, two keys each showing a door/window outline, below them arrows pointing inward towards a centre symbol (`→ ◇ ←`, "close guard door").
- **Start the program with the key** (figure: cycle-start key symbol, a rectangle with a circulating arrow and a "I" in the middle).

✓ **The workpiece is now being machined.**

On machines with **automatic guard door** (`automatische Schutzhaube`) you preselect the work area to be closed with these keys (figure: same key pair `→ ◇ ←`). The left key closes work area 1. The right key closes work area 2.

By pressing the two mushroom buttons (`Pilztaster`) mounted on the sides of the operating panel, you close the desired guard door(s) and automatically start the cycle, if this has been preset by a parameter.

It is important that the mushroom buttons are pressed simultaneously and held until the door(s) is (are) closed.

### 4.1.2 Stopping the machine (`Maschine anhalten`) (page 4-4)

**Caution** (attention pictogram): In case of tool breakage or cutting problems, stop the machine:

- Select selector switch `AG 1` or `AG 2`, depending on parallel or complete machining
- and key `Zyklus Stop` (cycle stop) (figure: rectangle with a circulating arrow and an "O" in the middle)
- and inform the setter (`Einrichter`).

### 4.1.3 Changing the workpiece (`Werkstück wechseln`)

- **After the aggregate group AG 1 or AG 2, or the machine, has stopped, the blue key(s) `"Schutzhaube auf"` (guard door open) light up.**
  - Press the left or right key; the corresponding guard door is unlocked. In non-split operation (`ungesplitteter Betrieb`) pressing one of the two keys is enough to unlock both guard doors.
    Figure: key pair with door outlines, arrows pointing outward (`← →`, "open guard door").
- **Open the guard door(s) and release the key(s).**
- **Grip the part (possibly with a crane).**
- **Open the chuck with the left foot switch and remove the part.**
- **Clean chips and dirt from the clamping jaws and insert a new part.**

On machines with **automatic guard door**, pressing these key(s) opens the guard door(s) automatically, according to the key(s) pressed, provided the function has not been programmed with cycle end (`Zyklusende`).

## For the retrofit

- Operating mode needed for production: `MASCHINE / AUTOMATIK` (p. 4-3).
- Operator panel has a selector switch `AG 1` / `AG 2` choosing which aggregate group (side) the start/stop keys act on; choice depends on parallel vs. complete machining (p. 4-3, 4-4). For complete machining the operator still selects one AG (which one is not stated).
- Keys: cycle start (symbol with "I"), cycle stop `Zyklus Stop` (symbol with "O"), a key pair "guard door close" (`→ ◇ ←`, green lamps) and "guard door open" (`← →`, blue lamps, text `Schutzhaube auf`), left key = work area 1, right key = work area 2 (p. 4-3, 4-4).
- Start enable: green key lamps + enables (`Freigaben`) on screen only after door(s) closed (p. 4-3).
- Door unlock: blue lamps light only when AG 1/AG 2 or the whole machine is stopped; pressing a key unlocks the corresponding door; in non-split operation one key unlocks both doors (p. 4-4).
- Clamping: right foot switch = clamp (hold at least 2 s), left foot switch = unclamp (p. 4-3, 4-4). (Chapter 3 says there is one foot switch set per spindle.)
- Automatic guard door option: two side mushroom buttons pressed simultaneously (two-hand) and held until closed; closing can auto-start the cycle if set by parameter; automatic opening at key press unless door opening is programmed at cycle end (p. 4-3, 4-4).
- No M-codes or part-transfer sequence on these pages.
