## 1.1 An wen wendet sich diese Anleitung? (Who is this manual for?)

(Page 1-3.)

This Gildemeister CNC lathe is a robust and powerful, but also technically demanding machine that requires careful handling. It may therefore only be operated by trained personnel.

The necessary knowledge can be acquired, among other ways, in special Gildemeister training courses.

In addition, the operator should be able to handle conventional lathes and know the technological fundamentals of metal cutting (e.g. cutting materials, workpiece materials, cutting values, cooling etc.). The design and working method of CNC lathes and CNC controls should also be familiar (e.g. setting up, tool offset, program call etc.).

We assume that the machine is operated and maintained only by trained personnel. Exceptions are simple, daily recurring tasks such as oil level checks or repeated loading of identical workpieces.

## 1.2 Was steht in dieser Anleitung? (What is in this manual?)

This manual describes the daily operation and maintenance of machine and control.

For operators who are not yet so familiar with the machine, chapter 5 "Bedienung von Maschine und Steuerung" (operation of machine and control) and chapter 6 "Einrichten" (setting up) are particularly important.

Simple, daily recurring routine tasks, which can also be carried out by semi-skilled helpers, are given in chapter 4 "Kurzanweisungen für Einleger" (short instructions for loaders).

We hope that this manual will be a good help to you in familiarization and with any problems that arise.

## 1.3 Was steht nicht in dieser Anleitung? (What is not in this manual?)

(Page 1-4. "nicht" is underlined in the heading.)

**Programmieren** (programming)
Actual programming is described in the programming manual (Programmierhandbuch).

**Technische Details** (technical details)
Technical details and repair instructions can be found in the technical documentation for service (Technische Unterlagen für den Service).

## 1.4 Hinweise (Notes)

For the sake of clarity, this operating manual does not contain all detailed information on all types of the product and cannot take into account every conceivable case of installation, operation or maintenance.

If you require further information or if special problems occur that are not dealt with in sufficient detail in the operating manual, you can request the necessary information from your Gildemeister agency.

> ✓ (check mark) This symbol means that the result of the inputs or keyboard commands is now present, i.e. the current state of control, screen or machine.

Changes serving technical progress are reserved.
