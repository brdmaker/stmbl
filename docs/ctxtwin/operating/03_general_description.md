## 3.1 Concept of the CTX twin (page 3-3)

The machine and the control of this machine are designed for front-side and back-side machining (`Vor- und Rückseitenbearbeitung`), where

- two identical or different work sequences can run in parallel or offset in time,
- complete machining, i.e. front and back side within one sequence (`Ablauf`), is possible.

Program functions can be converted automatically, so that the user can think as if working on a conventional single-slide lathe.

### 3.1.1 Aggregate groups (`Aggregategruppen`)

According to the machine concept, the control contains 2 aggregate groups, hereinafter called **AG**.

- each AG is autonomous on the operating and programming interface
- one AG can contain several spindles and also several slides
- each AG handles its own work area
- within one AG only one operating mode exists at a time
- different operating modes can exist in the two AGs at the same time, i.e. operating-mode splitting (`Betriebsarten-Splitting`)
- when operating-mode splitting is fully used, for safety reasons the work areas must be separated by a partition wall (`Trennwand`).

## 3.3 Optional assemblies (`Optionale Baugruppen`) (pages 3-6, 3-7)

The following assemblies are not part of the basic version of the machine. They are available as options.

1. **Bar guide / bar feed (`Stangenführung / Stangenvorschub`)**: The bar guide serves for exact guidance of bars outside the turning spindle. The bar feed pushes the bars forward automatically. A bar loading magazine additionally reloads bars from a magazine (stock).
2. **Spindle reducing tube (`Spindel - Reduzierrohr`)**: For bar machining, tubes matched to the bar Ø are needed in the turning spindle.
3. **Unloading device right, incl. conveyor belt and part ejector (`Abholeinrichtung rechts, einschl. Transportband und Teileauswerfer`)**: The unloading device picks the finished workpiece from the right spindle and carries it out of the work area via a conveyor belt.
4. **External data storage devices (`Externe Datenspeichergeräte`)**: external data storage devices, e.g. floppy disk Facit N 1100 or GNT 7102 NC-Data Drive.
5. **C axis (`C-Achse`)**: Operation with C axis, together with driven tools, allows contours to be produced on peripheral and end faces, e.g. pockets, polygons and hole patterns.
6. **Automatic work-area partition wall (`Automatische Arbeitsraumtrennwand`)**: The automatic work-area partition wall divides the machine into two work areas.
7. **Chip conveyor with coolant tank (`Späneförderer mit Kühlmittelbehälter`)**: The chip conveyor carries the chips out of the work area and at the same time serves as coolant tank. In the basic version the machine is equipped with a chip tray that also serves as coolant tank.
8. **Oil mist separator (`Ölnebelabscheider`)**: The oil mist separator extracts oil or coolant mist from the machine's work area.
9. **Overload clutch for X and Z axes (`Überlastkupplung für X- und Z-Achsen`)**: On overload this option brings the feeds in X or Z to a standstill.
10. **Tool measuring device, left and right (`Werkzeugmeßeinrichtung, links und rechts`)**: The tool measuring device serves to measure the tools in the machine's work area in the operating mode `HANDSTEUERN` (manual control). It is available at both spindles.
11. **Automatic guard door, left and right (`Automatische Schutzhaube, links und rechts`)**: The automatic guard door option allows automatic opening and closing of the guard door, also separately for each work area.
12. **Two-pressure clamping device, per spindle (`Zwei-Druck-Spanneinrichtung, je Spindel`)**: The two-pressure clamping device provides, selectably, two different programmable clamping forces at the chuck.
13. **Two-pressure coolant device (`Zwei-Druck-Kühlmitteleinrichtung`)**: provides, selectably, two different programmable coolant pressures in the work area.
14. **Coolant spray gun (`Kühlmittel-Spritzpistole`)**: allows rinsing off chips (contamination) in the work area.
15. **Coolant cleaning (`Kühlmittelreinigung`)**: by an additional device, e.g. band filter or pressure screen filter, the coolant is cleaned of contamination.
16. **Coolant through the turning spindle, per spindle (`Kühlmittel durch die Drehspindel, je Spindel`)**: serves mainly for flushing the clamping devices.
17. **Hollow clamping device Ø 52, left spindle (`Hohlspanneinrichtung Ø 52, Spindel links`)**: allows machining of bar stock or bar sections.
18. **Hollow clamping device Ø 52, right spindle (`Hohlspanneinrichtung Ø 52, Spindel rechts`)**: allows machining of longer workpieces in the right spindle.
19. **Signal lamp (3-fold) (`Kontrolleuchte (3-fach)`)**: located on the machine, shows various operating states.
20. **Oil and coolant drip tray (`Öl- und Kühlmittelauffangwanne`)**: prevents these substances from penetrating the shop floor.
21. **Equipment (`Ausrüstungen`)**: an adapted range of further parts, handling systems etc. is available for optimal machining of the workpieces.

## 3.4 Intended use of the machine (`Bestimmungsgemäßer Gebrauch der Maschine`) (page 3-8)

**Which parts?** This lathe is primarily suited for turning chuck and shaft parts. With the basic version you can make parts according to the work-area data. See 2.4, "Work area sheet 1" (`Arbeitsraum Blatt 1`) on page 2-6, or 2.5, "Work area sheet 2" on page 2-7.

**Which materials?** The usual steels, cast iron, copper, aluminium, brass, gunmetal (`Rotguß`), machinable plastics and resin-bonded laminated wood can be turned on this machine. If you are not sure whether your material can be machined on the machine, please ask your Gildemeister representative.

**Special suitability:** The machine is distinguished by its short set-up times. It is therefore particularly suited for the economical production of small to medium batch sizes at consistent quality.

It allows
- complete machining within the scope of the optional possibilities
- parallel machining of identical or similar parts on the two spindles.

**Clean and maintain regularly** (attention pictogram): The machine only works reliably and without faults if you clean and maintain it regularly. Therefore be sure to observe chapter 8.1, "Maintenance" on page 8-3, which describes maintenance.

## 3.5 Warning against misuse (`Warnung vor Mißbrauch`) (page 3-9)

Despite the safety and stability of the machine you must observe a few things:

**Caution: Do not turn ceramic parts.** Turning ceramic parts produces fine dust that penetrates every corner and quickly obstructs important mechanical functions. In addition, the lubrication and coolant systems can clog.

**Caution: Observe limit values.** When programming, observe the stated maximum speeds of the main drive and of the clamping devices, and the maximum feed forces, see 2.1, "Technical data" on page 2-3. These values must never be exceeded! Also allow for the rise in feed force as the cutting edge of the tool wears.

**Caution:** Also observe the manufacturer's data on permissible clamping pressure and clamping force of the clamping devices, and the limit value of the tool holder for maximum indexing operations per hour (`maximale Schaltungen je Stunde`), see 2.1, "Technical data" on page 2-3.

## 3.6 Safety devices (`Sicherheitseinrichtungen`) (page 3-10)

This machine has the safety devices described below. Beyond that, further safety measures are an integral part of the machine and control.

**Warning:** All safety devices are provided for personal protection. Taking them out of service or bypassing them is not permitted.

After repairs, the safety devices must be returned to their safe state.

Safety devices must be included in regular maintenance, see chap. 8.1, "Maintenance" on page 8-3. Parts subject to wear must be replaced in good time.

### 3.6.1 Key switch (`Schlüsselschalter`)

Access to certain operating modes or settings is only possible via key switch or password. The operator (company) must ensure by suitable operating instructions that these keys are used only by instructed and authorised users.

Parameters or setting values must be set according to the equipment used, e.g. the chuck. They must be adapted at every change.

### 3.6.2 Emergency-stop shutdown (`Not-Aus Abschaltung`)

These push-buttons are conspicuously marked red-yellow and are to be pressed in case of danger.

All movements are stopped. Drives that could lead to a hazard are switched voltage-free.

After the hazard has been removed and before restarting, the emergency-stop button must be unlatched.

### 3.6.3 Enabling key (`Zustimmtaste`)

Starting dangerous movements in manual mode is only possible when one hand presses an enabling key and the other hand presses the function key. When either key is released the movement is stopped.

### 3.6.4 Separating guards around the machining area (page 3-11)

The machining area holds special hazards from the movements of slides, tool holders and spindles taking place there. It is enclosed on all sides; access is only possible via guard door(s) (`Schutzhaube(n)`) that are mechanically locked and interlocked with the control. Dangerous movements can only be started when the guard door(s) is (are) closed.

The access conditions depend on the type of movement:

- with guard door(s) open:
  - running the spindle at max. 50 min⁻¹ with function key and enabling key
  - clamping and unclamping
  - indexing the tool holder at reduced speed with function key and enabling key
  - jogging the chip conveyor free in manual mode with function key and enabling key
  - in manual mode, slide movement at reduced speed, max. 1 m/min, with function key and enabling key
- movements of options for setting up, as long as the relevant function key and enabling key are held
- with guard door(s) closed, all movements are possible.

The enclosure and the guard door(s) with their safety window(s) (`Sicherheitsscheibe(n)`) are dimensioned so that parts flying off as a result of breakage or collision are safely retained. This applies only as long as permissible speeds and weights of clamping jaws are not exceeded.

After collisions, damaged parts must be replaced; this applies particularly to the safety window and its frame.

#### 3.6.4.1 Automatic work-area partition wall (operating-mode splitting)

To make sensible use of operating-mode splitting, the "Automatic work-area partition wall" available as an option is required. It ensures that when the two work areas are used individually (different work sequences in parallel or time-offset) the operator is not endangered, since in its closed state it prevents reaching into the other work area.

### 3.6.5 Speed monitoring (`Drehzahlkontrolle`) (page 3-12)

The spindle speeds (0 min⁻¹, 50 min⁻¹ and max. value) are each specially monitored. Opening the guard door is only possible with the spindles stopped; the spindles only start with the guard door closed.

The maximum permissible speed values of the machine are given in the technical data.

If the limit speed of the chuck is lower than the max. speed of the machine, this value must be entered as a parameter. Additionally this value must be set on the separate speed limiter for power chucks (`Drehzahlbegrenzung für Kraftspannfutter`) (option). Access to these settings is only possible via key switch or password.

### 3.6.6 Workpiece clamping (`Werkstückspannung`)

Safety in workpiece clamping is achieved by the following means:

- foot switches, which cause the clamping movement but stop the clamping process when released
- clamping-pressure monitoring (`Spanndrucküberwachung`), i.e. too low a clamping pressure prevents starting or causes stopping of the turning spindle
- clamping-stroke monitoring (`Spannhubüberwachung`), i.e. when the clamping jaws are in one of the monitored end positions, the turning spindle is prevented from starting
- safety clamping cylinders, which on a line break maintain the clamping force until the turning spindle has come to a stop.

When changing chucks, the proximity switches for clamping-stroke monitoring and the clamping pressure must be re-set. The limit speed must be changed as a parameter and in the speed monitoring.

Using a commercially available clamping-force meter, the clamping forces on the power chucks must be checked and recorded at regular intervals (see maintenance plan), according to the specifications of the draw-force diagram (`Zugkraftdiagramm`). This also applies after changing the chuck.

### 3.6.7 Hydraulics (page 3-13)

The pressure in the hydraulic system is monitored; if it falls below the set value, the machine is stopped.

### 3.6.8 Pneumatics (if fitted)

The pressure in the pneumatic system is monitored; if it falls below the set value, the machine is stopped.

### 3.6.9 Separating guards for setting and maintenance spaces

The machine is enclosed on all sides.

Access to spaces in which dangerous movements take place, for setting or maintenance work, is only possible through electrically monitored doors or flaps that open only with a special tool. A sign on these doors and flaps indicates that they may only be opened with the machine stopped, as otherwise there is a risk of tool breakage.

### 3.6.10 Noise protection (`Lärmschutz`)

The machine is designed so that the noise emission value at the workplace does not exceed the value stated in the technical data.

Cutting noise can exceed that value under unfavourable conditions. In such cases the noise emission values must be reduced by changing the cutting conditions, tools or clamping conditions.

### 3.6.11 Emissions

The machine is prepared for connection to an oil mist extraction system.

### 3.6.12 Chip conveyor (`Späneförderer`) (page 3-14)

Operation of the chip conveyor is only permitted with a chip bin properly placed underneath, so that reaching into the discharge chute of the chip conveyor is not possible. Chips must not be removed by hand. To clean the chip discharge opening, the machine must be switched off.

## 3.7 Lubricants and coolants (`Schmierstoffe und Kühlschmiermittel`) (page 3-15)

- At least 100 l hydraulic oil (= one tank filling)
- 20 l slideway oil (`Gleitbahnöl`) (for topping up the fresh-oil tank, capacity = 3 l). With automatic lubrication the consumption is approx. 0.5 l per 100 operating hours.
- 310 l coolant (= capacity of chip conveyor + coolant tank)
- At least 1 kg high-performance grease paste for greasing the chuck (must be greased every 8 operating hours).

### 3.7.4 Coolant for the integrated spindle motors (`Kühlmittel für die integrierten Spindelmotore`)

The cooling medium for the spindle motors is water with an addition of glycol. Mixing ratio:
- 95 % water
- 5 % glycol as corrosion protection

Recommendation, e.g.:
- Tyfocor, ethylene-glycol based, from Tyforop Chemie GmbH, Hamburg

**Warning: Tyfocor or an equivalent coolant is harmful to health! Take care when handling such media; observe the manufacturer's instructions.**

### 3.7.5 Handling lubricants and coolants (page 3-18)

**Warning: Oils, lubricants and coolants.** Because of their constituents (additives) these substances are a possible hazard to health and the environment.

Selection and use lie solely in the hands of the operator (company). An operating instruction to be drawn up by the operator, regulating the handling of these substances, should contain:

- designation of the substances
- hazards to people and the environment
- protective measures and rules of conduct, e.g.
  - wear protective gloves of resistant plastic
  - avoid contact with skin and eyes
  - do not inhale vapours and mist
  - fire, open flames and smoking are prohibited
- behaviour in case of danger, first aid
- proper disposal

Please clarify in good time how you can dispose of used lubricants and coolants in an environmentally sound way.

Lubricant vapours can arise during turning. For their removal Gildemeister offers oil mist separators.

## For the retrofit

- Control structure: the original control is organised in **2 aggregate groups (AG 1, AG 2)**, each autonomous in operation/programming, each with its own work area and its own operating mode; different modes in the two AGs at once = "operating-mode splitting", which requires the optional automatic partition wall (p. 3-3, 3-11). Maps naturally onto two LinuxCNC instances, one per side. The control type/model is not named on these pages.
- Twin concept: front- and back-side machining; two identical/different sequences in parallel or offset, or complete machining (front + back) in one sequence; program functions are converted automatically so the user thinks in single-slide-lathe terms (p. 3-3). Part transfer details are not on these pages.
- Axes: X1, Z1 (cross slide X1/Z1, left side), X2 and Z2 (slide X2; Z2 feed motor at right end of the bed) (p. 3-4, 3-5). Two integrated (motor-)spindles, left and right, water/glycol cooled by a cooling unit in the supply cabinet (p. 3-5, 3-17).
- Tool holders: one per side; driven-tool version uses a servomotor on the tool holder (p. 3-5). C axis is an option, used with driven tools (p. 3-6). Tool holder has a max. indexing-per-hour limit (Technical data p. 2-3) (p. 3-9). Maintenance chapter refers to Sauter documentation for the turret (p. 8-5).
- Chucks: hydraulic clamping cylinder + draw tube + chuck/collet per spindle; foot switch per spindle (left/right); options: two-pressure clamping (programmable), hollow clamping Ø 52 left/right, coolant through spindle (p. 3-5 to 3-7).
- Interlocks the new control must reproduce (p. 3-10 to 3-13):
  - guard doors mechanically locked and interlocked with the control; dangerous moves only with doors closed; doors open only with spindles stopped; spindles start only with doors closed;
  - doors open: spindle max. 50 min⁻¹, turret indexing at reduced speed, chip conveyor jog, slides max. 1 m/min, each only with function key + enabling key (two-hand); clamp/unclamp allowed;
  - spindle speed monitoring at 0 min⁻¹, 50 min⁻¹ and max.; chuck limit speed as parameter plus separate hardware speed limiter (option); settings protected by key switch/password;
  - clamping-pressure monitoring (too low -> no start / spindle stop), clamping-stroke monitoring with proximity switches (jaws in end position -> no spindle start), safety clamping cylinders hold force on line break;
  - hydraulic (and pneumatic if fitted) pressure monitored, machine stops below set value;
  - E-stop: all motion stopped, hazardous drives de-energised;
  - setting/maintenance doors electrically monitored.
- Options that need I/O if fitted: bar feed/loader, unloading device right with conveyor and part ejector, automatic guard doors (per work area), automatic partition wall, tool measuring device left/right (used in `HANDSTEUERN` mode), two-pressure coolant, chip conveyor, oil mist separator, overload clutch X/Z (stops feeds), 3-fold signal lamp (p. 3-6, 3-7).
- Lubrication: automatic slideway-oil lubrication, fresh-oil tank 3 l, consumption approx. 0.5 l / 100 h; hydraulic tank min. 100 l HLP32 (p. 3-15).
